# Changelog

## 1.0.0 - 2026-11-13
First public release.
- Live zone map and continent map with WoW's own player arrow, updated 10 times a second.
- Resizable window: tall = zone + continent, short = zone only. Remembers size and position.
- Finds the game on any monitor setup, windowed or full screen.
- Detailed maps (forests, towns, roads) when the Leatrix Maps addon is installed.
- Reads map pictures from your own WoW install with a small pure-Python reader - no compiled code.
